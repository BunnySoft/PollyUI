# PollyOS 首个 Alpha 路线

更新时间：2026-10-09。唯一任务源为 [POLLYOS-PLAN.json](POLLYOS-PLAN.json)；
本页解释版本范围，不另维护一套完成状态。执行清单从该 JSON 生成。

## Alpha 的范围

首个 Alpha 是**普通用户可启动、可进行日常基础操作、可集中手测的开发版**：

- Live ISO 直接进入普通用户桌面；安装版虚拟磁盘使用单 SYSTEM 与独立持久用户数据。
- 安装版能够完成首次设置、默认密码登录、失败重试；root 只用于维护，不进入 GUI。
- 基础窗口/任务栏/启动器、当前 XP 装饰、系统设置、本地音频、基础 Files 和打开保存可用。
- 普通注销、保存、关机/重启有明确用户操作和失败反馈。

Alpha **不等于**空白磁盘安装器、受保护生产桌面、完整 XP 1:1、实盘/目标硬件认证，
也不表示所有长期任务已完成。无锁屏和安装器等限制必须在候选说明中保留。

- **Shutdown GUI 未资格通过。** 正常应用关闭后最终确认曾显示后台刷新/no-action 提示，

  没有称为无害 harness 限制或已经修复；测试应用改在仅测试盘预置，不能当作运行时问题的修复。

## 集中手测短清单

仅在功能收尾、统一候选介质准备好后进行一轮；日常开发不为每项重复建 VM。

1. 新虚拟磁盘首次启动、双密码设置/取消、错误密码重试、普通用户进入桌面。
2. 注销/再登录、正常关机/重启；密码、初始化状态和一项用户文档/偏好不丢。
3. 窗口拖动/缩放、主题切换、任务栏/启动器和系统设置六页的基础操作。
4. Files 浏览/新目录/重命名，打开真实文本，新建保存和已有文件明确覆盖/变化重问。
5. 基本音频/已支持网络控制与服务不可用反馈；候选正常注销/关机，不把 VM 强制退出当持久性通过。

不自动接管用户正在使用的 PollyOS，不读取密码或密码哈希、不重置状态。
Live 公有开发密码仅属于 Live；安装版没有默认密码。

2026-10-08 用户选择全新测试环境，并要求复用现有 **PollyOS Hyper-V 配置**，
新 ISO/VHDX 固定放在 `D:\Temp\PollyOS\`，由用户自行更换介质；不另建宿主 VM、
弹出管理员授权或自动改旧磁盘。新 VHDX 保持未初始化，隔离 guest 的测试账户状态不回写发行盘。
当前代理仍无 Hyper-V 管理权限，因此新介质的 QEMU 检查与用户后续 Hyper-V 实测分开记录。
