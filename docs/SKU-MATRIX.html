Updated: 2026-10-21. Current product names: Mini / Compact / Standard. Chinese fonts and input are included from Compact upward. There is no -zh suffix or separate hardware tier. Mini is the former Alpine Micro desktop. Compact is the Debian Chinese lightweight target, using basic GOP/simpledrm display rather than vendor-specific editions. Standard carries the complete existing driver/firmware selection. Use bash tools/build.sh --os --help for the canonical product build entry.

This document records confirmed product boundaries and implementation status; it is not an executable build configuration. Target inclusion, source availability, packaging, service startup, and actual usability are distinct states. See delivery records for image identities and historical artifacts, and stack and sizes for size evidence.

A SKU name does not automatically imply audio, networking, PAM/login, installation, persistence, or updates. These have implementations in the existing Standard system, but their required scope in the new tiers remains to be defined. The Decorator and minimum application set must also be explicitly specified, packaged, and started. Mini's existing Alpine recipe integrates the basic application set below; current Standard also includes it, while Compact integration is not finalized. Including a Shell or copying JS resources does not establish their delivery.

The UI Host creates application windows, receives input, and submits rendered buffers to PollyWM over Wayland. It is not the compositor or a graphics-card driver. Wayland SHM submits CPU-rendered pixels through shared memory; a GPU presentation backend is a separate build/runtime choice. Shared Host source does not imply identical SDK binaries, build options, or delivery readiness.
