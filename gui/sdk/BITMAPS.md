# Byte-backed bitmap resources

`createBitmap(bytes, maxPixels)` decodes a PNG or JPEG from an `ArrayBuffer` or
`Uint8Array` into an owned GUI resource. Typed-array offsets and lengths are
respected, and the decoder copies the bytes; the caller may subsequently mutate
or release its input. `maxPixels` is a positive integer (at most `4294967295`);
invalid, incomplete, or oversized encoded images throw.

The returned handle has read-only `key`, `width`, and `height` properties. Use
`key` as an image source or `backgroundImage` value, retain the handle while any
view uses it, and call `close()` when finished. `closed` reflects explicit
release or GUI teardown; repeated `close()` calls are safe. Garbage collection
also releases an unreferenced handle.

Resources belong to the shared GUI realm, not individual windows. Closing a
child window does not invalidate handles used by other windows. Bridge teardown
releases all remaining images before VM destruction, including handles still
referenced by JS. Keys are generated by the GUI and are never reused across
realms. This API performs no file lookup and requires no SysRT or desktop service.
Application-specific path, file-size, image-count, and dimension policies belong
in the calling application.
