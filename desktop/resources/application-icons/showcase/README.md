# Showcase icon pack

Original 1024px masters and 256/128/64 exports for the app/capability showcase.
Generated by `desktop/tools/generate-showcase-icons.py` (Pillow, offline).

- `showcase-sheet.png` — 1800×1280 contact sheet with app names and status.
- `manifest.json` — machine-readable list, sizes and implementation status.
- `*-1024.png` — editable-resolution masters.
- `*-256/128/64.png` — launcher, taskbar, desktop and store sizes.

Style: soft skeuomorphic/modern, top highlight, 1–2px edge, soft drop shadow.
No platform logos, system icons or proprietary fonts are included.
