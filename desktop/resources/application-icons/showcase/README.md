# Showcase icon pack

Original 1024px masters and 256/128/64 exports for the app/capability showcase.
Generated by `desktop/tools/generate-showcase-icons.py` (Pillow, offline).

- `showcase-sheet.png` — combined 1800×1480 contact sheet.\n- `showcase-apps.png` — larger 1800×1160 app-only board.\n- `showcase-system.png` — 1800×540 system-capability board.
- `manifest.json` — machine-readable list, sizes and implementation status.
- `*-1024.png` — editable-resolution masters.
- `*-256/128/64.png` — launcher, taskbar, desktop and store sizes.

Style: macOS-inspired superellipse tiles, layered gradients, a soft inner rim and
ambient shadow with restrained specular light. No platform logos, system icons
or proprietary fonts.
